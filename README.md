# To-Do List App

A simple and user-friendly To-Do List Application built using HTML, CSS, and JavaScript. This project helps users organize their daily tasks, manage their work, and stay productive.

### Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Simple and clean user interface.
- Easy task management.

### Technologies Used
- HTML – Structure of the application.
- CSS – Styling and layout.
- JavaScript – Functionality and interactivity.

### Purpose
The main purpose of this project is to improve my web development skills and understand how HTML, CSS, and JavaScript work together to build an interactive web application.
